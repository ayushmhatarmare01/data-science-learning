# Data Science Learning

A practical learning repository covering Data Science fundamentals, data analysis, statistics, and visualization using Python.

## About This Repository

This repository documents my progress in learning Data Science through hands-on exercises and projects. It builds on Python fundamentals and prepares me for Machine Learning, Generative AI, and Agentic AI.

## Topics

- **NumPy:** Arrays and numerical computing
- **Pandas:** Data cleaning and manipulation
- **Matplotlib:** Data visualization
- **Seaborn:** Statistical visualization
- **Statistics:** Descriptive statistics and probability
- **SQL:** Querying and analyzing data
- **Exploratory Data Analysis (EDA):** Finding patterns and insights
- **Projects:** Practical data analysis exercises
